- [Account deletion worker](account-deletion-worker.md) — durable job PostHog → RevenueCat → Auth, pg_cron drain every 2 min; PostHog bulk_delete is ASYNC since 2026-09 (`persons_queued_for_deletion`, deleted stays 0), worker accepts deleted+queued == found since f80999d / version 13; deploy via MCP with the three `functions/...` files; auth-first deletion is feasible (job FK `set null`), open decision
- [`randomId()`, never `crypto.randomUUID()`](random-id-not-crypto-randomuuid.md) — `crypto.randomUUID` is secure-context-only and went missing on a real Galaxy S24 Ultra (WebView 131, `https://localhost`, 2026-09-17), throwing inside a `useState` initializer and taking the dialog down; `src/utils/randomId.ts` falls back to `getRandomValues` then `Math.random`, all six call sites converted — never call `crypto.randomUUID()` directly, and don't use `randomId` for anything that must be cryptographically strong
- [Chatbot memory lives in Redux](chatbot-memory-in-redux.md) — the "change a saved recipe → new-recipe duplicate" bug was client state, not the model: `knownRecipeIds`, unsent `[Proposal Outcomes]` and the proposal counter were page state and reset on every navigation while the conversation survived, so the edge function rejected correct edits; since 2026-09-23 all three live in `chatbotSlice` and `resetChat` clears them together
- [Edge-function models and reasoning](edge-function-models.md) — chatbot = `gpt-6-sol` (since 2026-09-23, Terra before) with `reasoning: { effort: "low" }` and a one-shot retry without `previous_response_id`; search parser = `gpt-6-luna` (since 2026-09-23) with `reasoning_effort: "none"`; both since 2026-09-10 (gpt-5.4-nano before); `scripts/chatbot-model-eval.ts` scores the chatbot's edit-vs-new tool choice per model; never pass `temperature` to a gpt-5 model; deploy via the Supabase MCP `deploy_edge_function` (no CLI on the Mac), files listed in the note
- [`signed_in` after identify](signed-in-after-identify.md) — `pendingSignIn.ts` (2026-09-11): call sites mark the method, `fetchUserData` spends it right after a successful `posthog.identify()` (person props freeze at ingestion), sign-out clears it; magic link = fragment token remembered at load and matched against the session the auth listener reports (web), or marked in `AppUrlListener` (Android App Link); NEVER trigger on Supabase's `SIGNED_IN` alone (fires on session recovery + tab focus); in-memory, a reload before identify loses it
- [Android: R8 im Release-Build](android-r8.md) — seit 2026-09-13 `minifyEnabled true` + `shrinkResources true` + `proguard-android-optimize.txt`, weil Play ab Februar 2027 je 25 % Optimierung/Verschleierung/Schwund bei > 10 MB DEX verlangt (Plateful: 39 MB); `optimization.keepRules.ignoreFrom('com.revenuecat.purchases:purchases-store-amazon')` ist Pflicht, weil dessen Consumer-Regeln ein globales `-dontoptimize` mitbringen (sonst 0 % Optimierung); Werte aus `BUNDLE-METADATA/com.android.tools/r8.json` der AAB lesen; Mapping liegt in der AAB, nichts hochladen; AGP 9 nicht nötig und durch RevenueCats Plugin blockiert
- [Play Console: die drei empfohlenen Aktionen](play-console-warnings.md) — Edge-to-Edge-Warnung kommt allein aus `@capacitor/status-bar` (abgekündigte `Window.setStatusBarColor`-Aufrufe in Methoden, die wir nicht nutzen; Ionic: not planned), verschwindet nur ohne das Plugin; Mapping-Hinweis erledigt sich durch R8 von selbst; native Symbole gibt es nicht, weil `libandroidx.graphics.path.so` (Compose via RevenueCat UI) gestrippt ausgeliefert wird, `debugSymbolLevel` extrahiert nichts
- [Review accounts: hidden password sign-in](review-accounts.md) — Google rejected 1.1 twice for a "paywall" the reviewer could not get past because magic link and Google Sign-In are both unusable for them; since 2026-09-16 typing a review address in `/login` or `/signup/email` reveals a password field (`src/lib/reviewSignIn.ts`, mirrors iOS `AuthStore.reviewEmail`); `androidreview@` for Play, `chatgptreview@` for OpenAI's plugin reviewers and `claudereview@` for Anthropic's connector reviewers, who hit the same dead end at `/oauth/consent` when connecting the MCP server; own account and household each, premium is a never-expiring `environment = 'MANUAL'` row and the gate is `household_entitlements`, not the RevenueCat SDK; re-seed with `node scripts/seed-review-account.mjs android|chatgpt|claude` in the iOS repo; Play Console instruction text in the note
