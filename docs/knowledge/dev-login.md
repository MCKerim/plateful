# Dev login: the test household without a mailbox

_Off the dev server (`npm run dev`, or the Android app with live reload) the email sign-in page `/signup/email` shows a "Dev-Login" link when `.env.local` holds `VITE_DEV_EMAIL` and `VITE_DEV_PASSWORD` (the iOS repo's `DevConfig.swift` test account `dev@plateful.test`); `src/lib/devSignIn.ts` is null in production builds, so nothing ships._

Since 2026-10-12 (first on the unlinked `/login` page, deleted the same day: the sign-up pages do everything it did). Shown only when `import.meta.env.DEV` is true, which is the Vite dev server, never a `vite build`, so neither the APK built from `dist/` nor Vercel ever carries it; for the emulator use `npx cap run android -l --host localhost --port 5173 --forwardPorts 5173:5173` against a running `npm run dev`. Production sign-in is a magic link or Google, which an agent driving the browser cannot complete; the review accounts need their own passwords. The dev account's credentials live only in the git-ignored `.env.local` (`*.local` is ignored) and the iOS repo's git-ignored `DevConfig.swift`. To set it up, copy `testEmail` / `testPassword` from there into `.env.local` as the two variables; Vite restarts the dev server on the change. The account cooks, plans and shops against the production project in its own household, like the iOS Dev Menu does.
